# قارئ الكتب

تطبيق PWA عربي محلي لقراءة النصوص الواضحة من صفحات الكتب بالكاميرا والبحث في فهرس الكتب. الشاشة الرئيسية مقصودة لتبقى بسيطة: كاميرا مباشرة، بحث كتابي، وإعدادات.

## التشغيل

```bash
npm start
```

افتح التطبيق عبر HTTPS أو عبر معاينة Webdev حتى تسمح المتصفحات باستخدام الكاميرا. ارفع ملف Excel/CSV أولًا، ثم PDF الصفحات من الإعدادات؛ بعدها تبدأ المطابقة محليًا. يمكن تثبيت التطبيق من قائمة المتصفح.

## ملاحظات القراءة

الصور لا تُحفظ: يتم أخذ إطار مؤقت من الفيديو داخل الذاكرة، تحسينه، وتمريره إلى Tesseract.js المحلي بالعربية والإنجليزية. PDF النصي يُفهرس مباشرة، والصفحات الصورية تُقرأ OCR عند الفهرسة. كل جهاز يحتفظ ببياناته في IndexedDB مستقلًا.
